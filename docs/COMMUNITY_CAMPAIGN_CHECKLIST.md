# Community Campaign Checklist

Simple checklist for posting earning campaigns in Telegram/Discord/X.

Last updated: 2026-05-27

## Before posting

- Confirm campaign is active in admin dashboard.
- Confirm dates/time window and claim limits.
- Confirm chain scope (Solana, Aptos, or both).
- Confirm CTA link works (`https://aptcasino.fun` or promo short link).
- Confirm copy matches the exact reward terms.

## Message structure

Use this order for better conversion:

1. Hook line (`9 ways to earn`, `new coupon live`, etc.)
2. Clear reward/value bullets
3. Exact action path (`Profile -> Earn`)
4. Link
5. Risk/eligibility line

## Safety and trust line (recommended)

Include one line like:

`Rewards depend on campaign rules, wallet activity, and anti-abuse checks.`

## Post cadence

- Major update post: 1x per week
- Promo reminder: every 48-72 hours
- Final call: 6-12 hours before expiry

## Fast QA after posting

- Link preview shows correct OG image
- No broken line wraps in Telegram
- Coupon code case is correct
- Community manager pin/reply enabled
